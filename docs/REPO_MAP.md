# Repo Map — react-portfolio

Reference doc describing the structure of this codebase: what renders where, what props/data each piece takes, and where to make common edits. Generated by reading the actual source (not guessed from names). Keep this updated when the structure changes materially.

## 1. Stack overview

- **Build tool**: Vite 5 (`vite.config.js` — bare-bones, just `@vitejs/plugin-react`, no aliases).
- **Framework**: React 18.2, plain JS/JSX (no TypeScript; `@types/react*` are devDeps for editor intellisense only).
- **Routing**: `react-router-dom` is a dependency but **unused** — no `Routes`/`Route`/`BrowserRouter` anywhere. This is a single page; the 4 "sections" are navigated by horizontal scroll-snap, not URL routes.
- **Styling**: mixed —
  - CSS Modules per section: `HeroStyles.module.css`, `SkillsStyles.module.css`, `ProjectsStyles.module.css`, `ContactStyles.module.css`, `FooterStyles.module.css`.
  - Plain global CSS: `src/App.css` (theme CSS variables + global layout classes like `.horizontal-scroll-container`, `.scroll-indicator`), plus `LiquidCursor.css`, `MoreNavigation.css`, `ResumePreview.css`, `LiquidSwitches.css`, `WaterSwitch.css`.
  - `src/index.css` is **empty** but still imported by `main.jsx`.
  - `sass` is a devDependency but no `.scss` files exist — unused.
- **npm scripts** (`package.json`): `dev` (vite), `build` (vite build), `lint` (eslint), `preview` (vite preview).
- **Email**: contact form uses `emailjs-com` (not the also-installed `@emailjs/browser`).
- **index.html**: loads Google Fonts (`Roboto Mono`, `Rubik`) via CDN, sets favicon to `./src/assets/Favicon.png`, and defines an inline `<filter id="goo">` SVG gooey-blur filter used by the liquid cursor/switch effects.

## 2. App shell / render tree

```
main.jsx
└─ <React.StrictMode>
   └─ <ThemeProvider>            (src/common/ThemeContext.jsx)
      └─ <App />                 (src/App.jsx)
```

`App.jsx` renders, inside `<ResumePreviewProvider>`:

1. Inline `<svg>` gooey filter (`id="goo"`, separate from the one in `index.html`, different filter params).
2. Fixed div (top:20px, right:20px, zIndex:1100) containing `<LiquidContainerSwitch />` — the theme toggle.
3. `<LiquidCursor />` — custom animated cursor overlay.
4. `.horizontal-scroll-container` div with 4 `<section className="horizontal-section">`s:
   - `#hero` → `<Hero />`
   - `#skills` → `<Skills />`
   - `#projects` → `<Projects />`
   - `#contact` → `<Contact />`
5. `<Footer />`
6. `<MoreNavigation />` — fixed radial pie nav menu.
7. `<ResumePreview />` — conditional overlay/iframe.
8. `.scroll-indicator` — dots, one per section, `active` class on `sections[activeSection]`.

**App.jsx own state/logic**:
- `activeSection` (number, index into `sections = ['hero','skills','projects','contact']`).
- `useEffect` on mount: listens for `scroll` on `.horizontal-scroll-container` → sets `activeSection = Math.round(scrollLeft / window.innerWidth)`.
- Same effect: listens for `keydown` (`ArrowRight`/`ArrowLeft`) on `document` → smooth-scrolls the container by `window.innerWidth` per step, clamped to `sections` bounds.

There is **no dedicated Navbar/Header component** — that role is split between `MoreNavigation` (section jumping) and `LiquidContainerSwitch` (theme toggle), both rendered as fixed overlays directly in `App.jsx`.

## 3. Component reference

### `src/sections/Hero/Hero.jsx`
- No props. Renders profile image, name (`Suraj Singh`), title (`FullStack Developer`), 3 social icon links, a bio line, and a Resume button.
- **Social links (hardcoded)**: Twitter/X → `https://x.com/SurajS041`, LinkedIn → `https://www.linkedin.com/in/suraj-singh41/`, GitHub → `https://github.com/SUPR1M3`.
- Each social icon is rendered as **two overlapping `<img>`s** (light + dark SVG variant), crossfaded via inline `style={{opacity: theme==='light'?1:0}}` — not swapped by `src`.
- Hooks: `useTheme()` → `{theme, toggleTheme}`; `useResumePreview()` → `{resumeButtonRef, toggleResumePreview, handleMouseEnter, handleMouseLeave, isHovering, resumeClicked}`.
- Styles: `HeroStyles.module.css` (classes: `container`, `heroImageContainer`, `hero`, `info`, `description`, `resumeButtonContainer`, `button`, `gradientContainer`, `gradient`, `label`, `hoverHint`).
- Assets used: `hero-img.webp`, `linkedin-{light,dark}.svg`, `twitter-{light,dark}.svg`, `github-{light,dark}.svg`.

### `src/sections/Hero/LiquidContainerSwitch.jsx`
- No props. The actual theme-toggle UI (rendered fixed top-right by `App.jsx`).
- Renders `div.liquid-container-switch.variant-1.{theme}` with an inner `liquid-fill` and floating `sun.svg`/`moon.svg` icons (`active` class toggled by `theme`). `onClick` → `toggleTheme()`.
- Hooks: `useTheme()`. Styles: `./WaterSwitch.css` (plain CSS).

### `src/sections/Hero/LDSwitch.jsx` — **dead code**
- Not imported anywhere. Superseded by `LiquidContainerSwitch`. Safe to ignore/delete.

### `src/sections/Skills/Skills.jsx`
- No props. Renders a 3D-rotating skill carousel, a static "Achievements" panel, and a "Skills Index" list.
- **Skills data** — inline `const skills = [...]` array, 12 entries, schema:
  ```js
  { name: string, category: string, proficiency: number /*0-100*/, icon: string /*emoji*/, color: string /*hex*/, colorRgb: string /*"r, g, b"*/ }
  ```
  Entries: Python (Backend), PyTorch (AI/ML), JAX (AI/ML), NumPy (AI/ML), Hugging Face (AI/ML), HTML (Frontend), CSS (Frontend), JavaScript (Frontend), Node.js (Backend), React (Frontend), C++ (Backend), Docker (Tools).
- **Achievements** are hardcoded JSX (not array data): "Dean's Merit List", "ACM ICPC Chennai Regional Qualifier".
- State: `currentIndex` (active carousel index), `isAutoRotating` (bool), `ringMetrics` (`{radius, cardWidth, cardHeight}`, computed responsively via `ResizeObserver`).
- Refs: `carouselRef`.
- Effects: `ResizeObserver` recomputes `ringMetrics`; `setInterval(3000ms)` auto-advances `currentIndex`.
- Helpers: `hexToRgb(hex)`, `getCardPosition(index)` (3D ring math), `handlePrevious`, `handleNext`, `handleCardClick(index)`.
- Styles: `SkillsStyles.module.css` (~869 lines; has 2 `data-theme` rules).
- Does **not** use `Skill.jsx`.

### `src/sections/Skills/Skill.jsx` — **dead code**
- Props: `skillname` (string). Renders a checkmark icon pair + skill name. Not imported by `Skills.jsx` or anywhere else — leftover from a pre-carousel list design.

### `src/sections/Projects/Projects.jsx`
- No props. Renders an infinitely-scrolling marquee "wall" of project cards.
- **Projects data** — `useMemo` `baseProjects`, 10 entries, schema:
  ```js
  { name: string, description: string, category: string, link: string /*GitHub URL*/, icon: <imported image>, color: string /*hex*/, colorRgb: string, tech: string /*comma-separated*/ }
  ```
  Entries (name — category): Covfefe (Web App), BookLetter (Database App), Space Invaders (Game), Reel Good (Web App), Portfolio (Website), LinkBot (Automation Tool), RocketCanvas (Web App), PacManRL (AI/ML), Base Transformer (AI/ML), Python Coding Agent (Agent).
- A second `useMemo` `wallProjects` triples `baseProjects` (adds `_wallId` per copy) for a denser marquee loop; the list is rendered twice in the DOM (`wallTrack`) for seamless CSS-animation looping — 6x total card renders.
- Helper: `hexToRgb(hex)` (duplicated from `Skills.jsx` — no shared util).
- Each card: icon image, name, category, description, tech line, "View Project →" link (`target="_blank" rel="noopener noreferrer"`).
- Styles: `ProjectsStyles.module.css` (~326 lines).
- Icon assets imported: `Covfefe.png`, `Favicon.png` (reused as Portfolio's icon), `BookLetterIcon.png`, `SpaceShip.png`, `ReelGoodIcon.png`, `PacManRLIcon.png`, `LinkBotIcon.png`, `RocketCanvas Icon.png`, `transformer-icon.png`, `agent-icon.png`.

### `src/common/ProjectCard.jsx` — **dead code**

### `src/sections/Contact/Contact.jsx`

### `src/common/MoreNavigation.jsx`
- No props. SVG-based radial "pie" nav menu; expands on hover into 4 segments.
- **Nav items** — inline array, schema `{ id, label, icon }`: `{hero, Home, 🏠}`, `{skills, Skills, 💡}`, `{projects, Projects, 💼}`, `{contact, Contact, 📧}`.
- State: `isOpen` (bool). Refs (mutable, non-render): `containerRef` (`.horizontal-scroll-container` DOM node), `hoverIntentTimeoutRef`, `scrollTargetLeftRef`, `isScrollLockedRef`, `queuedSectionIdRef`, `activeTargetSectionIdRef`.
- Geometry constants: `innerRadius=60`, `outerRadius=120`, plus derived `centerX/centerY/svgSize/viewPadding/viewBoxSize/middleRadius`.
- Key functions: `getScrollLeftForSection(id)`, `requestScrollToSection(id, shouldCloseMenu)` (smooth scroll + scroll-lock/queue + 700ms failsafe unlock), `scheduleHoverScroll`/`cancelHoverScroll` (180ms hover-intent debounce), `polar(radius, angle)`, `createSegmentPath(...)`, `calculateItemPosition(index, total)`.

### `src/common/LiquidCursor.jsx`
- No props. Custom cursor: exact-follow dot + 3 trailing "gooey" balls (lerp factors 0.95/0.15/0.30) animated via `requestAnimationFrame`, combined with the SVG `goo` filter.
- Hooks: `useTheme()` (class name only). Refs: DOM nodes + position trackers (`mousePos`, `ball1Pos`, `ball2Pos`, `ball3Pos`).
- Effect: sets `document.body.style.cursor='none'`, attaches `mousemove`, runs RAF loop; cleans up on unmount.
- Styles: `LiquidCursor.css`.

### `src/common/ResumePreview.jsx`
- No props. Renders `null` unless `showResumePreview` (from context) is true; otherwise a card with a close button and `<iframe src={CV}>`.
- `CV` imported from `../assets/Suraj_Singh_Resume_Final.pdf` (there's also an older, unused `Resume_Suraj_Singh.pdf`).
- Consumes `useResumePreview()`: `{showResumePreview, isClosing, resumePreviewRef, closeResumePreview}`.
- Styles: `ResumePreview.css`.

### `src/common/ResumePreviewContext.jsx`
- Exports `useResumePreview()` hook + `ResumePreviewProvider({children})`.
- State: `showResumePreview` (bool), `resumeClicked` (bool — pinned open via click vs. just hover), `isHovering` (bool), `isClosing` (bool, exit animation flag).
- Refs: `resumePreviewRef`, `resumeButtonRef` (outside-click detection), `hoverTimeoutRef`, `closeTimeoutRef`.
- Context value: `showResumePreview`, `resumeClicked`, `isHovering`, `isClosing`, `resumePreviewRef`, `resumeButtonRef`, `openResumePreview`, `closeResumePreview`, `toggleResumePreview`, `handleMouseEnter`, `handleMouseLeave`.
- Behavior: hover-in opens preview after 200ms; hover-out (if not clicked) closes with a 300ms exit animation; click toggles pinned-open (`resumeClicked`) and enables click-outside-to-close via a `mousedown` document listener.

## 5. Theming

- **`src/common/ThemeContext.jsx`**:
  ```js
  const [theme, setTheme] = useState(() => localStorage.getItem('theme') || 'dark'); // default 'dark'
  useEffect(() => {
    document.body.setAttribute('data-theme', theme);
    localStorage.setItem('theme', theme);
  }, [theme]);
  const toggleTheme = () => setTheme(prev => prev === 'light' ? 'dark' : 'light');
  ```
  Exposed via `useTheme()` as `{theme, toggleTheme}`. (The `894b115 Fix: Default Theme Change` commit changed the fallback default from `'light'` to `'dark'`.)
- **CSS variables** in `src/App.css`:
  ```css
  :root{
    --background-color: white;
    --btn-color: #0987f2;
    --btn-text-color: #fff;
    --project-card-bg: #ffffff00;
    --text-color: #222;
    --form-text-color: #555;
    --footer-text-color: #888;
  }
  [data-theme='dark']{
    --background-color: #222;
    --btn-color: #fff;
    --btn-text-color: #222;
    --project-card-bg: #fff;
    --text-color: #fff;
    --form-text-color: #fff;
    --footer-text-color: #bbb;
  }
  ```
  Plus a `[data-theme='light'] .scroll-dot`/`.scroll-dot.active` override.
- **Per-component light/dark asset swap pattern**: Hero social icons, `LiquidContainerSwitch`, `LDSwitch` (dead), `Skill.jsx` (dead) all import both a light and dark SVG and crossfade via inline `opacity` — both images stay in the DOM.
- Theme-aware component CSS beyond `App.css`: `MoreNavigation.css` (8 `data-theme` rules), `SkillsStyles.module.css` (2 rules). Other module CSS relies solely on the global CSS variables.
- The user-facing toggle is `LiquidContainerSwitch` (rendered by `App.jsx`) — `LDSwitch` is unused.

## 8. Quick-edit cheatsheet

| To change... | Edit... |
|---|---|
| Add/edit a project card | `src/sections/Projects/Projects.jsx` → `baseProjects` array (add matching icon import) |
| Add/edit a skill | `src/sections/Skills/Skills.jsx` → `skills` array |
| Add/edit an achievement | `src/sections/Skills/Skills.jsx` → JSX in the Achievements panel |
| Change a social link | `src/sections/Hero/Hero.jsx` → the relevant `<a href>` |
| Change EmailJS service/template/key | `src/sections/Contact/Contact.jsx` → `serviceId`/`templateId`/`userId` consts |

| Adjust theme colors | `src/App.css` → `:root` and `[data-theme='dark']` CSS variables |
| Add/remove a scroll-nav section | `src/App.jsx` (sections array + `<section>` block) **and** `src/common/MoreNavigation.jsx` (`navigationItems`) — both must stay in sync since section ids are shared strings |
| Change default theme | `src/common/ThemeContext.jsx` → `localStorage.getItem('theme') || 'dark'` fallback |
| Change hero bio/name/title | `src/sections/Hero/Hero.jsx` — plain inline JSX text |
